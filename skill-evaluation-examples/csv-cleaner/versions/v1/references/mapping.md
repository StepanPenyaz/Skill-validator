# Column Name Mapping

Canonical column names used by `scripts/clean.py` when normalizing headers:

| Source header variants        | Canonical name |
|--------------------------------|----------------|
| `email`, `e-mail`, `mail`      | `email`        |
| `full name`, `name`, `fname`   | `full_name`    |
| `phone`, `tel`, `telephone`    | `phone_number` |
| `zip`, `postcode`, `zip_code`  | `postal_code`  |
